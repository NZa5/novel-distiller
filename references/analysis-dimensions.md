# 小说作者深度分析维度

这是一套包含 35 个固定维度的问题库与分析顺序，不是要求每个样本强行制造发现的清单。最终画像的 `coverage` 必须逐项声明下表中的机器 ID；不适用时标记 `not_applicable`，证据不足时标记 `insufficient` 并说明缺口，没有稳定规律时标记 `no_stable_finding`，不要用最接近的标签代替真实结论。

## 固定维度注册表

| ID 范围 | 分析层 | 固定机器 ID |
|---|---|---|
| 01–07 | 语言与文体表面 | `syntax_rhythm`、`paragraph_organization`、`diction_register`、`function_words_cohesion`、`rhetoric_imagery_senses`、`sound_repetition`、`chinese_specific_features` |
| 08–13 | 叙事话语 | `narrator_evaluative_stance`、`viewpoint_focalization_interiority`、`speech_dialogue_organization`、`narrative_time`、`information_release`、`openings_transitions_endings` |
| 14–17 | 人物与关系 | `character_introduction_reference`、`characterization_channels`、`desire_agency_character_arc`、`relationships_social_network` |
| 18–20 | 事件、情节与结构 | `event_selection_density`、`causality_escalation`、`conflict_plot_arc` |
| 21–24 | 空间、世界、主题与类型 | `space_environment`、`world_rules_social_texture`、`theme_motif_value_structure`、`genre_tradition_reader_contract` |
| 25–34 | 深层语言与宏观动态 | `topic_reference_ellipsis`、`modality_evidentiality_negation`、`conversation_pragmatics_repair`、`humor_irony_satire`、`plot_threads_chapter_rhythm`、`viewpoint_transition_matrix`、`relationship_network_evolution`、`foreshadowing_payoff`、`motif_imagery_trajectory`、`period_style_drift` |
| 35 | 负向画像 | `negative_profile_avoidance` |

每条规则和证据只能引用一个固定机器 ID；更细的现象写入规则的 `category`。同一现象横跨多个维度时建立相互引用的规则，不要把多个 ID 拼成一个自由文本值。

## 分开三个层次

- **局部观察**：某个句子、段落、场景或章节实际出现了什么。
- **跨样本规律**：这种选择是否在分离样本中重复，或是否随场景、角色、视角和情节阶段规律变化。
- **写作动作**：生成新文本时，应在什么条件下作出什么选择，又应避免什么。

局部观察不能直接升级为作者规律。主题解释、读者效果和写作建议都必须能回指到可定位的文本现象。

## 建议分析顺序

### 第一遍：建立客观地图

先标记人物、地点、时间、事件、视角、场景边界、对话轮次、回忆与插叙、信息揭示点，不急着评价风格。为每个场景写一句功能摘要：谁想达成什么，受到什么阻力，场景结束时什么发生了变化。

### 第二遍：分析语言与叙事话语

观察句段运动、词汇语域、修辞和感官选择，再检查叙述者、视角、时间、言语呈现和信息控制。这里回答“故事怎样被讲出来”。

### 第三遍：分析人物与故事系统

分析人物塑造、关系与权力、事件因果、冲突升级、情节结构、空间和世界规则。这里回答“作者习惯选择什么故事材料，并怎样让它们运转”。

### 第四遍：跨样本归纳

把同一维度放到相近场景中比较，再跨场景、跨人物、跨章节或跨作品比较。区分稳定、条件、可变和不确定结论，并主动寻找反例。

### 第五遍：转化为写作控制项

只把能说明触发条件、执行顺序、使用节制和读者效果的结论写入作者画像。保留作者的变化范围，不把不同模式平均成一种声音。

不要让 35 个维度停留为彼此孤立的标签。把同一场景中反复共同出现的三到七条规则编成“特征组合”：记录触发条件、执行顺序、相互增强或冲突关系、适用场景模式和失败表现。后续场景包以这些组合为核心，而不是同时激活全部规则。

完成初步画像后，按每条规则的适用条件主动检索反例；再补读欠覆盖作品、章节、场景、视角和关系。每轮记录新增规则、新反例和未解决维度。连续两轮都没有新增且不存在未解决维度，才可声明分析饱和。

## 发现卡

每项重要发现至少记录：

| 字段 | 要回答的问题 |
|---|---|
| finding_id | 这条发现的稳定编号是什么？ |
| 分析层级 | 句子、段落、场景、章节、作品、阶段还是作者？ |
| 适用条件 | 哪种视角、人物、关系、场景、压力或情节阶段？ |
| 可观察现象 | 原文具体做了什么，不使用空泛形容词？ |
| 运作机制 | 这些选择怎样组合、按什么顺序发生？ |
| 读者效果 | 它改变了速度、距离、判断、悬念、人物印象还是情绪？ |
| 正向证据 | 哪些分离样本支持它，定位在哪里？ |
| 反例 | 哪些样本没有这样写，原因是否可解释？ |
| 对照证据 | 同类对照文本中相同、不同，还是未提供？ |
| 归类与可信度 | 稳定、条件、可变或不确定；高、中或低？ |
| 写作动作 | 新场景在什么条件下应怎样执行？ |
| 禁用与节制 | 什么写法会破坏该机制，使用频率有何限制？ |

## 一、语言与文体表面

### 1. 句法与节奏 `syntax_rhythm`

- 句子主要靠并列、从属、递进、转折、插入、重复还是省略推进？
- 主语是持续明确、频繁省略，还是在人物与环境之间滑动？
- 句首如何启动，句中如何延宕，句末落在动作、名词、判断、感觉还是悬而未决的信息上？
- 长短句怎样成组，停顿怎样形成加速、迟疑、压迫或余韵？
- 作者是否在特定场景改变句法，例如行动时切短、回忆时延长？

句长统计只能提示回看位置。真正的规则要解释句子内部怎样运动。

### 2. 段落组织 `paragraph_organization`

- 一个段落通常只承担一个功能，还是让观察、动作、记忆和判断逐层渗透？
- 换段由说话人、动作完成、视线转移、时间跳跃、情绪转折还是信息揭示触发？
- 段首先承接什么，段尾留下什么；相邻段落之间是因果、对照、递进、跳切还是留白？
- 独句段、超长段和重复段式在什么位置出现，承担什么压力？

### 3. 用词与语域 `diction_register`

- 名词偏具体物件、社会身份、自然物、身体部位还是抽象概念？
- 动词偏动作结果、动作过程、感知、判断、言说还是状态？
- 修饰语提供精确区别、情绪评价、节奏填充还是感官质地？
- 书面语、口语、方言、术语、旧词、新词与外来词怎样混合？
- 哪些词汇只属于题材、时代、人物或某部作品，不能上升为作者规律？

### 4. 功能词与衔接 `function_words_cohesion`

- 连接词、指代词、程度副词、否定词、时间词和语气成分如何组织逻辑与态度？
- 作者偏显式说明因果与转折，还是依赖排列、动作和上下文让读者补足？
- 重复出现的功能词是否跨样本稳定，还是某个人物的口语习惯？

### 5. 修辞、意象与感官 `rhetoric_imagery_senses`

- 比喻来自人物经验、自然、器物、身体、职业、宗教还是社会秩序？
- 修辞是解释陌生事物、强化情绪、制造反讽，还是改变观看角度？
- 视觉、听觉、触觉、嗅觉、味觉、温度、重量和空间感如何分配？
- 意象是一次性装饰，还是在后文变形、回响并承担主题或结构功能？
- 作者偏先给整体再给细节，还是从一个异常细节扩展到整体？

### 6. 声音与重复 `sound_repetition`

- 音节长短、叠词、排比、复沓、回环和标点停顿怎样塑造声音？
- 重复是强调、讽刺、迟疑、仪式感、人物执念还是结构呼应？
- 哪些声音模式只在对白、内心或高潮段落出现？

### 7. 中文特有观察项 `chinese_specific_features`

- **文白比例**：文言结构、书面语和现代口语怎样切换，切换由谁、何时触发？
- **四字结构**：成语、固定搭配和自造四字格是压缩信息、抬高语势还是制造反差？
- **量词选择**：常规量词、方言量词和创造性量词怎样改变画面与人物身份？
- **语气词**：啊、呢、吧、罢、么等如何区分关系、态度与时代感？
- **标点行为**：逗号、分号、破折号、省略号、冒号和引号如何参与句法、犹疑和声音控制？
- **对仗与排比**：结构对称是理性归纳、情绪推进、讽刺还是叙述者姿态？
- **典故与引语**：来源是否被说明，谁能理解，它是权威、共同记忆、戏仿还是人物区隔？

## 二、叙事话语

### 8. 叙述者与评价姿态 `narrator_evaluative_stance`

- 谁在讲述，叙述者是否作为人物存在，知识边界在哪里？
- 叙述者何时解释、判断、概括、讽刺、同情或保持沉默？
- 叙述可靠性来自事实矛盾、认知限制、自我辩护，还是语言态度？
- 作者如何让读者与叙述者靠近或拉开距离？

### 9. 视角、聚焦与内心 `viewpoint_focalization_interiority`

- 感知中心是谁，视角切换通过什么信号完成？
- 外部动作、身体感受、直接心理、回忆、联想和判断各占什么功能？
- 内心是被叙述者转述、人物直接说出，还是出现贴近人物语言的自由间接表达？
- 人物不知道的信息如何被限制、暗示或泄露？

### 10. 言语呈现与对白组织 `speech_dialogue_organization`

- 直接引语、间接引语、自由间接引语、概述和沉默怎样搭配？
- 对话标签、伴随动作、停顿、打断、答非所问和话轮长度怎样分配？
- 对白承担事实、关系、行动、回避、威胁、试探还是自我暴露？
- 关键信息被直说、错说、晚说，还是只让读者从反应中推断？
- 不同人物是否真的拥有不同句法、词汇、礼貌策略和信息权限？

### 11. 叙事时间 `narrative_time`

- 故事时间与叙述顺序是否一致；倒叙、预叙、插叙如何进入和退出？
- 哪些时刻被场景化放慢，哪些被概述、跳过或反复讲述？
- 同一事件由几个人、在几个时间点重新解释？
- 时间标记明确还是模糊；模糊带来迷失、普遍性、记忆感还是悬念？

### 12. 信息释放 `information_release`

- 读者、视角人物和其他人物分别知道什么，知识差在哪里？
- 作者主要制造结果悬念、原因好奇、突发惊奇，还是读者先知的戏剧反讽？
- 线索通过物件、动作、对白、叙述判断、背景说明还是结构并置出现？
- 提示的显著度、间隔和重复次数怎样控制；揭示后是否让旧细节获得新意义？
- 作者解释到什么粒度，哪些部分故意让读者补足？

### 13. 开篇、转场与结尾 `openings_transitions_endings`

- 开篇先给人物、异常、环境、声音、判断、行动还是缺失的信息？
- 场景之间通过时间、地点、物件、动作、话题、视角或意象连接？
- 章节结尾落在决定、后果、发现、未答问题、意象回响还是情绪余波？
- 钩子推动下一事件，还是迫使读者重看已经发生的事件？

## 三、人物与关系系统

### 14. 人物引入与指称 `character_introduction_reference`

- 人物先以姓名、身份、关系、外貌、动作、声音还是他人评价出现？
- 姓名、称谓、代词和省略怎样表达距离、权力与关系变化？
- 作者何时补充背景，是否让读者先形成判断再修正？

### 15. 人物塑造通道 `characterization_channels`

- 外貌、习惯动作、物品、环境、语言、内心、他人反应和关键选择分别承担什么？
- 性格是由叙述者概括，还是由反复选择逐渐显露？
- 矛盾特征怎样共存；人物是否在不同关系中表现出不同自我？
- 情绪通过命名、身体、动作、感知偏差、语言失常、沉默还是环境投射表达？

### 16. 欲望、能动性与人物弧 `desire_agency_character_arc`

- 人物公开目标、隐秘欲望、恐惧、误解和底线是什么？
- 人物主动发起多少关键事件，又有多少时间只作反应？
- 决定来自性格、关系、信息变化、外部压力还是偶然？
- 转变是认知、价值、能力、身份还是关系变化；文本用哪些重复或对照让它可见？
- 人物不改变时，作者如何表现其固执、循环或悲剧性？

### 17. 关系与社会网络 `relationships_social_network`

- 关系以亲属、利益、制度、欲望、秘密、照料、竞争还是共同经历连接？
- 权力来自身份、资源、知识、情感依赖、暴力或话语控制？
- 请求、拒绝、命令、谈判、试探、欺骗、和解怎样发生？
- 沟通依靠面对面对白、书信、电话、传闻、物件还是第三者？
- 关系改变时，称谓、距离、话轮、身体位置和信息分享如何同步变化？
- 群体、家庭、组织或社区只是背景，还是对人物选择具有因果力量？

## 四、事件、情节与结构

### 18. 事件选择与密度 `event_selection_density`

- 作者把什么算作值得写出的事件：动作、决定、发现、谈话、回忆、感觉变化还是日常重复？
- 一个场景包含多少事件单元，事件边界由动作完成、目标变化还是信息变化划分？
- 实际发生、回忆发生、假设发生、传闻发生和未发生之事怎样区分？
- 哪类事件被详细呈现，哪类只用一句概述？

### 19. 因果链与升级 `causality_escalation`

- 事件之间依靠明确因果、人物动机、时间相邻、主题并置还是偶然连接？
- 作者在行动前解释原因，行动中暗示，还是后果出现后才补充？
- 阻力怎样逐级增加；升级来自成本、时间、信息、关系还是道德压力？
- 意外后果如何回流并改变下一次选择？
- 高潮由人物决定、外部事件、误解解除、信息揭示还是多个因果汇合触发？

### 20. 冲突与情节弧 `conflict_plot_arc`

- 核心冲突发生在人与人、人与自我、人与制度、人与环境、价值之间还是认识之间？
- 风险是生命、资源、身份、关系、尊严、信念还是理解？
- 情节按任务、调查、追逐、关系变化、成长、循环或碎片并置组织？
- 障碍、尝试、失败、转折、代价和解决以什么节奏排列？
- 结局解决事件、关系、认知和主题中的哪些，又保留哪些开放性？

## 五、空间、世界与主题

### 21. 空间与环境 `space_environment`

- 场景空间先以地图式整体、人物路线、感官碎片、物件还是社会功能建立？
- 人物如何移动、停留、被限制或被空间观看？
- 环境只是气氛，还是提供资源、阻力、信息、象征或事件原因？
- 私人、公共、边界和过渡空间怎样对应关系与权力？

### 22. 世界规则与社会质地 `world_rules_social_texture`

- 经济、职业、技术、法律、礼俗、阶层、家庭和组织规则如何进入正文？
- 作者通过解释、行动后果、对话争议、日常程序还是陌生人物提问传递设定？
- 世界规则是否一致，例外由什么代价和权限决定？
- 物质条件和制度怎样限制人物，而不是只充当背景资料？

### 23. 主题、母题与价值结构 `theme_motif_value_structure`

- 哪些问题被不同人物、事件和意象反复重新提出？
- 母题在重复时发生了什么意义变化？
- 文本把哪些行为写成可理解、可原谅、可笑、可耻或不可裁决？
- 作者让叙述者、人物、情节后果和结构并置分别表达什么立场？它们是否互相冲突？
- 结尾关闭的是问题还是答案；歧义来自证据不足、价值冲突还是刻意多义？

### 24. 类型、传统与读者契约 `genre_tradition_reader_contract`

- 类型信号何时出现，作者遵循、延迟、混合还是反转了哪些惯例？
- 典故、互文、历史记忆和前文本怎样影响读者判断？
- 文本默认读者知道什么，又为哪些知识提供解释？
- 元叙事、自我指涉或形式实验在何处改变阅读方式？
- 时代、平台、题材和类型的共有习惯必须与作者特有选择分开。

## 六、深层语言与宏观动态

### 25. 话题链、指代与省略 `topic_reference_ellipsis`

- 一个段落或场景持续谈论谁或什么，话题如何建立、保持、切换和重新激活？
- 姓名、称谓、代词、零指代和主语省略怎样控制清晰度、距离、速度与悬念？
- 旧信息怎样承接，新信息落在句首、句中还是句末；焦点由语序、语气成分、重复还是标点标记？
- 指代暂时不明是来源噪音、无意歧义，还是让读者主动追踪视角和人物的稳定机制？

### 26. 情态、证据性、否定与判断强度 `modality_evidentiality_negation`

- 叙述者和人物怎样表达可能、必须、应该、愿望、推测、听闻、目击、回忆和确信？
- “似乎、仿佛、大概、据说、想来、当然”等判断来源属于谁，可信度怎样变化？
- 否定作用于事实、意图、身份、情绪还是读者预期；否定范围是否被延迟到句末才明确？
- 作者怎样在断言、保留、反问、自我修正和沉默之间控制判断力度？

### 27. 对话语用、礼貌与修复 `conversation_pragmatics_repair`

- 每个话轮实际执行请求、命令、拒绝、威胁、安慰、试探、撒谎、转移还是确认中的哪种行为？
- 问答、邀请—回应、指责—辩护等邻接结构是否完整，缺席的回应意味着什么？
- 人物怎样维护或攻击面子，使用敬语、缓和、暗示、越界、装傻和第三方转述？
- 误听、口误、打断、重说、自我修正和他人修复怎样暴露权力、紧张与亲疏？
- 人物是否会根据关系对象调整语域、句长、信息量和直接程度？

### 28. 幽默、反讽与讽刺 `humor_irony_satire`

- 效果来自语义反转、知识差、夸张、降格、错位、一本正经、重复回调还是叙述评价？
- 谁知道笑点，谁成为目标，谁没有意识到反讽；读者比人物多知道什么？
- 幽默用于缓压、加深残酷、建立亲密、保护人物，还是攻击制度与价值？
- 信号显性还是隐性，出现频率和位置怎样避免破坏人物或场景压力？

### 29. 多线情节与章卷节奏 `plot_threads_chapter_rhythm`

- 主线、支线、人物线、调查线和主题线怎样交错，切线由因果、信息、时间还是情绪触发？
- 每章承担建立、推进、逆转、延迟、汇合、余波还是换气中的什么功能？
- 作者怎样维护未闭合问题，多久返回一次，返回时增加信息、代价还是重新解释？
- 章、卷与全书尺度上的场景化、概述、跳跃和停顿形成怎样的节奏曲线？

### 30. 视角转移矩阵 `viewpoint_transition_matrix`

- 哪些视角可以直接相邻，哪些必须经过时间、空间、章节或物件桥接？
- 转移信号、进入成本和退出方式是什么；读者何时确认新的感知中心？
- 作者偏跟随行动者、受影响者、知情者还是误解者，为什么在此处转移？
- 每次转移增加、隐藏或重新解释了哪些信息；是否存在长期不被进入的关键视角？

### 31. 关系网络演化 `relationship_network_evolution`

- 关系边在章节推进中怎样从陌生、合作、依赖、竞争、控制、破裂到修复？
- 谁连接不同群体，谁被孤立，谁掌握资源、秘密、情感债务或叙述注意力？
- 一条关系变化怎样传导到第三人、群体和制度，而不是只影响双方？
- 称谓、空间位置、话轮、行动协作和信息权限是否同步变化，还是故意错位？

### 32. 伏笔、误导与回收 `foreshadowing_payoff`

- 每条种子首次出现在哪里，以物件、异常动作、语言漏洞、规则、空缺还是重复意象进入？
- 中间经过几次强化、变形、遮蔽或误导，间隔和显著度怎样控制？
- 回收解决事件、人物、关系、主题还是世界规则；是否同时重释早期细节？
- 哪些种子故意不完全回收，留下的是开放性、续作接口还是证据不足？

### 33. 意象与母题轨迹 `motif_imagery_trajectory`

- 意象或母题每次由谁感知、在什么场景出现、携带什么情绪和价值？
- 它是原样重复，还是在尺度、感官、载体、方向和评价上逐步变化？
- 多条意象轨迹是否在高潮或结尾汇合，又是否被人物赋予彼此冲突的意义？
- 哪些意象属于单部作品题材，哪些观察和变形机制能跨作品成立？

### 34. 时期、作品与风格漂移 `period_style_drift`

- 哪些语言、视角、结构和价值选择跨时期稳定，哪些随时间、题材、平台或笔名改变？
- 变化是渐进、突变、周期回返，还是只由某部作品的视角和人物造成？
- 版本、编辑、翻译、连载节奏和媒介变化能否解释表面漂移？
- 后续写作包应复现哪个时期；哪些跨时期规则可以保留，哪些必须按时期分流？

## 七、负向画像

### 35. 回避与节制 `negative_profile_avoidance`

作者“长期不做什么”也可能具有区分度，但只能从语料归纳：

- 哪些情绪通常不被直接命名？
- 哪类背景信息不会一次讲完？
- 哪些修辞、视角跳转、对白标签、高潮方式或结尾方式明显受到节制？
- 当文本接近某种俗套时，作者习惯如何偏转？
- 哪些看似显眼的手法实际上只出现一次，不应复制？

不要预先套用通用的“AI 味清单”。负向规则同样需要分离证据、反例和适用条件。

## 覆盖与停止规则

- 最终机器画像必须按固定注册表声明全部 35 个维度；声明状态不等于强行得出规律。
- 每次分析都应覆盖语言、叙事话语、人物关系、事件情节四个层面；空间世界、主题类型按语料适用性处理。
- 一个维度可以得出“未发现稳定规律”，这比勉强制造结论更可靠。
- 表层频率、单个金句、单个人物口头禅和某一高潮写法只能作为候选，不能单独代表作者。
- 新一轮阅读如果只增加同义描述，没有新增证据、条件、反例或机制，就停止扩写该结论。
- 最终画像优先保留能区分作者、能指导具体选择、又经得住反例检验的规则。
