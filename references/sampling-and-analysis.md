# 取样与分析

## 先确定画像层级

- **片段画像**：只描述当前段落怎样运作。
- **作品画像**：描述同一部小说反复出现的写法。
- **阶段画像**：描述作者某个创作时期或某种笔名下的写法。
- **作者画像**：需要跨作品、跨场景仍然重复的证据。

画像名称必须与证据范围一致。译作主要反映译者与版本的语言选择；合著、代笔、重度编辑或明显改版的文本应单独分组。

## 建立语料清单

为每个样本记录：

| 字段 | 内容 |
|---|---|
| sample_id | 简短稳定编号 |
| 作品与定位 | 书名、卷章、场景或行段 |
| 文本规模 | 实际统计字符数或大致长度 |
| 叙事条件 | 人称、视角人物、叙事时态、距离 |
| 场景类型 | 开篇、对白、行动、调查、抒情、过渡、高潮、收束等 |
| 角色条件 | 在场人物、说话人、关系阶段 |
| 来源状态 | 完整、节选、OCR、编辑版、未知 |
| 证据定位 | 索引 chunk_id、来源 SHA-256、段落范围和内容字符范围 |

优先让样本覆盖不同场景，而不是连续截取大量同质段落。连续章节适合分析作品节奏；相隔较远的章节和不同作品更适合判断稳定规律。

## 两层分析

### 第一层：每个样本怎样运作

为每个样本建立证据卡：

1. 这个场景要完成什么；
2. 叙述者站在哪里，知道多少，评价多少；
3. 句子怎样推进、停顿、转折和收束；
4. 段落按动作、观察、念头、对白还是信息组织；
5. 作者选择哪些名词、动词、修饰语、感觉和意象；
6. 情绪通过命名、身体、动作、环境、沉默还是反讽传递；
7. 对白怎样分配信息、权力、潜台词和角色差异；
8. 场景从什么压力开始，在何处转向，以什么余波结束。

每条发现记录“现象 → 机制 → 效果 → 定位”，不要只贴“简洁、细腻、电影感”等标签。

### 第二层：跨样本归纳

把相同维度放在一起比较：

- 跨场景仍重复的是稳定候选；
- 随场景、角色或紧张程度规律变化的是条件候选；
- 只出现一次的是局部手法；
- 出现明显反例且无法解释的规则降为可变或不确定。

统计范围应与比较范围一致。例如，行动场景的短句比例应先与作者自己的其他行动场景比较，再决定它是否属于作者规律。

## 表层统计

`scripts/analyze_style.py` 读取 UTF-8、带 BOM 的 UTF-16、GB18030 和 Big5 `.txt`/`.md`，按文件输出：

- 非空白字符、段落与句子数量；
- 句长与段长的均值、中位数、四分位数和范围；
- 短句、中句、长句比例；
- 中文引号内文本占比；
- 常用中文标点的每千字符频率；
- 多文件之间的指标范围。

先检查电子书是否存在固定行宽造成的硬换行：如果几乎每个三十余字的排版行后都有一个空行，普通模式会把排版行误认成段落。此时使用 `--reflow-hard-wrap`；工具按高频行宽特征逐文件判断，只重排命中的文件，因此硬换行原文可以与正常段落草稿混合比较。报告和 JSON 会记录每个文件是否实际执行了重排。

再检查篇末是否附有编辑注释。文件用独立的“注释/注釋”标题分隔正文与说明时，使用 `--strip-annotations`，让统计在该标题处停止。脚注标记、OCR 异体和其他版本噪音仍需在语料清单中记录并人工核对。

这些数据用于发现值得回到原文核对的问题。句长接近不代表叙述声音接近；不同场景的数值差异也可能正是作者的条件风格。

## 长篇切块与证据检索

先为长篇语料建立可重复使用的索引：

```powershell
python .\scripts\corpus_index.py build .\corpus --output .\work\corpus-index.jsonl --chunk-chars 1800
```

每条 JSONL 记录保存原文、来源文件、SHA-256、段落范围、内容字符范围和表层指标。原文件变化后，来源哈希也会变化，旧定位不能继续当作同一版本的证据。

按草稿表层节奏寻找候选样本：

```powershell
python .\scripts\corpus_index.py search .\work\corpus-index.jsonl --query-file .\draft.txt --top 4 --include-text
```

按正文关键词或人物名寻找证据时重复使用 `--contains`。检索结果只是候选；还要人工核对视角、场景功能、情绪强度和章节位置。

## 对照作者

用户同时提供目标作者和对照作者语料时，先按相近年代、题材、场景和篇幅分组，再运行：

```powershell
python .\scripts\compare_style.py contrast --target .\target --control .\control --output .\work\author-contrast.md
```

报告比较句段、对白、标点和功能词在分块样本中的中位数与四分位范围。区分度只负责排列核查顺序。差异必须回到原文解释其场景条件、机制和效果，才能进入作者画像。

## 证据标准

重要规则至少要回答：

- 它出现在哪些相互分离的样本？
- 它在相同场景和不同场景中分别怎样表现？
- 有没有反例？反例能否由角色、视角、情节阶段或场景类型解释？
- 它影响读者体验、人物形象或剧情推进的机制是什么？
- 生成新文本时，模型应做出什么具体选择？

无法回答最后一个问题的观察不进入写作规则，只保留在分析笔记中。

## 留出验证

语料足够时，在归纳最终规则之前预留若干相互分离的章节或场景，不用它们建立画像。画像完成后再检查：

1. 稳定规则是否能解释留出样本中的同类选择；
2. 场景矩阵能否把留出样本分到正确模式；
3. 哪些表面差异能由视角、角色、场景压力或章节位置解释；
4. 哪些反例迫使规则从稳定降为条件、可变或不确定；
5. 写作包是否误用了某一篇作品独有的道具、口头禅或结构。

留出验证的目的不是证明所有作品一样，而是检验画像能否同时识别作者的共同选择和有条件的变化。样本很少时不强行留出，改为降低画像层级与可信度。
