# 风格对照与回炉

## 建立可比基线

选择与草稿在视角、场景功能、情绪强度和章节位置上最接近的原文样本。表层数据与原文细读都按这个基线比较；全语料平均值只用于观察背景。

## 对照矩阵

| 维度 | close | partial | drift 时的证据 |
|---|---|---|---|
| 叙述者姿态与视角距离 | 选择与切换机制一致 | 大体一致但局部失焦 | 越权知道、评价强度或内心访问方式不同 |
| 句法与节奏 | 句子推进和停顿落在对应模式 | 表层接近但转折方式不同 | 连续句型、连接、落点显著异质 |
| 段落组织 | 换段与段落功能相似 | 长短接近但功能混杂 | 段落只按长度切分或堆叠多种功能 |
| 用词与语域 | 具体程度、动词和修饰方式一致 | 少量词域偏移 | 抽象判断、套语或陌生语域占主导 |
| 描写与感官 | 注意力选择和观察顺序一致 | 感官相近但缺少功能 | 描写对象、密度或意象来源不匹配 |
| 情绪传递 | 作者惯用通道与克制度一致 | 情绪成立但表达路径不同 | 解释取代动作、身体、环境、停顿或反讽 |
| 对白与角色声音 | 话轮、潜台词和人物差异成立 | 个别角色趋同 | 所有人共享同一语法、语气和信息量 |
| 信息释放 | 提示、延迟与揭示顺序一致 | 节点正确但过早说明 | 直接解释、重复总结或隐藏方式不同 |
| 场景与章节运动 | 开场压力、转折、余波和收束相似 | 单个环节偏弱 | 没有关系变化、代价或作者式结尾动作 |
| 招牌动作 | 在合适条件下自然出现 | 机制出现但痕迹明显 | 缺失或集中堆叠成模仿表演 |

标签是编辑优先级，不是数学评分。每个 `partial` 或 `drift` 都要指出草稿中的具体表现、对应画像规则和修改动作。

## 表层数据复核

对草稿运行 `scripts/analyze_style.py`，与匹配样本比较：

- 看完整分布和场景范围，而不是只看平均句长；
- 对白占比接近时，继续核对话轮、潜台词和角色差异；
- 标点频率接近时，继续核对停顿出现在什么语义位置；
- 数值偏离时，先判断剧情压力或场景功能能否解释。

量化偏差只有在对应到可感知的文本机制后才进入修订清单。

匹配原文已经单独保存时，可直接生成偏差排序：

```powershell
python .\scripts\compare_style.py draft --reference .\matched-source --draft .\draft.txt --output .\work\draft-comparison.md
```

工具按原文分块范围检查句段、对白、标点和功能词，把指标标成 `close`、`partial` 或 `drift`。这些标签仍需结合场景条件和原文细读解释。

比较多个修订版本时，先固定要观察的指标，再记录每版有多少项落在匹配样本范围之外；这个数量只表示需要回看原文的位置，不换算成“相似度百分比”。某项数值接近而整体节奏变差时，以文本机制和阅读效果为准。不要为了命中标点或对白比例而机械添加破折号、问句或话轮。

## 找出最暴露作者差异的三处

优先处理：

1. 会让读者立刻感到叙述者换人的偏差；
2. 贯穿多个段落并持续放大的偏差；
3. 破坏角色声音、信息节奏或章节收束的偏差。

逐项写出：原句或定位、偏差机制、目标规则、修订策略。修改覆盖范围应尽量小，避免为了调整标点而重写已经成立的情节和人物行为。

## 对比回炉

1. 保留事实卡和已经有效的段落。
2. 先改深层选择，再改句段表面：叙述距离 → 信息与段落 → 情绪和对白 → 句法、用词、标点。
3. 重新运行同一对照矩阵，确认目标偏差已经缩小，同时没有引入新的剧情错误。
4. 默认完成一轮定向重写和一次复核。只有仍存在明确、可修的高影响偏差时再继续。

## 可复现盲测

使用没有参与画像归纳的原文，与生成稿建立固定随机种子的匿名测试包：

```powershell
python .\scripts\blind_style_test.py prepare --original .\holdout --generated .\drafts --output-dir .\blind-test --seed 20260830
```

把 `blind-pack.md` 和空白 `blind-responses.csv` 交给不知道答案的读者，保留 `blind-key.json`。读者填写 `original/generated`、1–5 信心和暴露身份的具体特征后运行：

```powershell
python .\scripts\blind_style_test.py score --key .\blind-test\blind-key.json --responses .\blind-test\blind-responses.csv --output .\blind-test\blind-score.md
```

同时查看生成稿被当作原文的比例、真正原文的识别情况、整体辨识正确率和文字理由。不要只挑一个数字下结论；把不同读者反复指出的暴露特征加入漂移纠正表，再做下一轮生成与盲测。
