# 作者画像模板

作者画像是分析与生成之间的正式接口。使用实际内容替换模板，不保留空标题。

## 1. 身份与范围

- 画像名称：
- 语料范围：
- 覆盖作品、章节与场景：
- 可代表的创作阶段或题材：
- 数据状态：完整文本、节选、OCR 或其他版本信息
- 当前可信度概述：

## 2. Master Voice

用一段紧凑文字说明这个作者面对人物、世界和读者时的基本姿态。覆盖叙述距离、价值态度、情绪温度、注意力落点和信息控制。这里写底层声音，不堆形容词。

## 3. 证据地图

| rule_id | 类型 | 规则 | 适用条件 | 目标作者证据 | 对照作者检验 | 反例与解释 | 可信度 |
|---|---|---|---|---|---|---|---|
| R01 | 稳定/条件/可变/不确定 | 具体可执行规则 | 场景、角色、视角 | chunk_id、来源哈希和范围 | 对照中相同/不同/未提供 | 已核对的反例 | 高/中/低 |

对照语料存在时，注明该规则是“目标作者显著偏好”“共有时代/题材惯例”还是“证据仍不足”。共有惯例可以保留为背景，但不作为最有区分度的作者规则。

## 4. 稳定写作基因

分别提炼：

- 叙述者姿态与视角距离；
- 句子推进、连接和落点；
- 段落功能与换段逻辑；
- 用词语域、动词选择和修饰密度；
- 观察顺序、感官偏好和意象来源；
- 情绪传递方式；
- 信息隐藏、提示、揭示和回看；
- 转场、时间处理与章节收束；
- 冲突、升级、转折和余波的组织方式。

每项都写成可执行动作，例如“先写可见动作，再让身体反应暴露情绪，最后用一句克制判断收束”，并附适用范围。

## 5. 场景模式矩阵

| 场景模式 | 叙事距离 | 句段运动 | 对白 | 描写与感官 | 情绪通道 | 信息与结尾 |
|---|---|---|---|---|---|---|
| 日常/过渡 | | | | | | |
| 对峙/冲突 | | | | | | |
| 行动/高潮 | | | | | | |
| 反思/抒情 | | | | | | |
| 开篇/章节结尾 | | | | | | |

根据真实语料增删行。场景矩阵负责保存作者的变化范围，避免把所有场景写成同一种节奏。

## 6. 人物与对白引擎

为主要角色建立语音卡：

- 词汇层级与常用句式；
- 发言长度、主动程度和回避方式；
- 称谓、语气词、停顿、打断和动作节拍；
- 公开意图与潜台词之间的距离；
- 面对不同关系对象时怎样变化；
- 两到四条带定位的短例证。

另写作者跨角色共享的对白组织规律，避免把作者习惯误判成某个角色独有特征。

## 7. 招牌动作

每个招牌动作记录：

- 触发条件；
- 执行顺序；
- 对读者产生的效果；
- 出现频率或使用节制；
- 原文定位；
- 在新文本中的等价实现方式。

招牌动作可以是信息延迟、视线转移、意象回响、冷处理、对话错位、动作替代心理说明或特定章节钩子。复现机制，不复制原文专属句子。

## 8. 表层数据范围

记录实际统计语料与运行日期，再填写典型范围：

- 句长分布；
- 段落长度分布；
- 对白占比；
- 关键标点密度；
- 各场景模式之间的明显差异。

保留范围和分组差异，不压成一个全书平均值。

## 9. 漂移纠正表

| 漂移现象 | 为什么不像 | 应恢复的作者机制 | 修订动作 |
|---|---|---|---|
| 示例：连续解释人物感受 | 原作者主要让动作和停顿承担情绪 | 行为证据先于判断 | 删除解释句，补一个能改变关系的动作 |

这里只记录从作者样本与实际生成中观察到的偏差。每次用户确认“像”或“不像”后，更新相应规则及证据。

## 11. 写作包

压缩成每个场景都能重新注入的短包：

1. Master Voice；
2. 当前场景模式；
3. 当前视角和角色语音卡；
4. 五到八条最有区分度的规则；
5. 两到四个短例证的定位与机制摘要；
6. 当前最容易出现的三项漂移及纠正动作；
7. 本场景应使用的表层数据范围。

写作包应足够短，能反复使用；完整画像保留证据和条件，负责在需要时回查。
