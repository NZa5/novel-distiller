# Installation

1. Copy or clone the `novel-distiller` folder into a Skill directory supported by your Agent.
2. Keep `SKILL.md` and `references/` together with their relative paths unchanged.
3. Reload or restart the host if it discovers Skills only at startup.
4. Confirm that the host lists or activates `novel-distiller` before using it on important text.

Skill locations and invocation syntax differ by host and can change between versions. Follow the current documentation for your Agent rather than assuming that one path or command works everywhere.

Novel Distiller itself needs no Python package, separate API key, or build step. The host Agent may still require its own account, model access, and attachment support.
