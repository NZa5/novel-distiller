# Changelog

## Unreleased — 3.0.0

- Simplified the project into a dependency-free prompt Skill.
- Removed formal JSON Schemas, checkpoint/resume contracts, validator and evaluation scripts, fixed-output tests, and CI/release automation.
- Replaced strict machine-contract claims with a suggested JSON shape and honest long-context limitations.
- Expanded the analysis framework with world, theme, symbol, information, scene, perspective, reader-experience, and conditional genre lenses.
- Deepened the integrated prose-style lens with sentence, paragraph, diction, rhythm, voice, dialogue, description, rhetoric, transition, tone, sampling, and evidence guidance.
- Kept evidence discipline, uncertainty labels, source-data trust boundaries, privacy guidance, and copyright limits.

## Skill 2.0.0

- Published strict output Schema 2.0.0 and resumable state protocol 1.0.0.
- Added source-boundary, privacy, quote-budget, bilingual discovery, and deterministic Skill artifact contracts.
